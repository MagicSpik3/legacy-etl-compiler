Architecture

What is the legacy-etl-compiler system?

  • Takes an existing SPSS/PSPP pipeline and converts it into another language (e.g., R).
  • Uses an intermediate representation to make the compiler deterministic, testable, and optimizable.
  • The key intermediate representation is a State Machine built from the original script.

Why not translate directly to R?

  • The Syntax Trap: Direct translation maps SPSS syntax directly to R syntax. This fails because the two languages have fundamentally different execution models.
  • Hidden Side Effects: SPSS is highly procedural and relies on a mutable “active dataset.” R leans towards functional dataframe manipulation.
  • Brittle Output: Without an intermediate logical layer, the resulting R code is often unreadable, unoptimized, and extremely difficult to test for true equivalence.

Why via a State Machine?

  • A State Machine models the true underlying territory of the data lifecycle, independent of the map (the syntax) of either language.
  • It makes dependencies explicitly clear and eliminates hidden side effects.
  • It safely allows the compiler to reorder, optimize, and mathematically verify transformations while ensuring behavioral equivalence.

What is a State Machine?

  • A mathematical model of a program where each operation explicitly transitions the system to a new, immutable state.
  • Instead of mutating variables, we create new versions at each step (e.g., X1, X2, X3).
  • Each step is deterministic, making complex, messy legacy pipelines significantly easier to reason about.

Order Matters

Side‑by‑Side Comparison

Original Order

X <- 1        → X = 1
Y <- X * 3    → Y = 3
X <- X + 1    → X = 2
Z <- X * 7    → Z = 14
sum(X, Y, Z) 
Result = 19

Modified Order

X <- 1        → X = 1
Z <- X * 7    → Z = 7
X <- X + 1    → X = 2
Y <- X * 3    → Y = 6
sum(X, Y, Z)
Result = 15

State Machine View (Same Logic)

State Machine (Compiler-Level)

  • Operations become nodes in a directed acyclic graph.
  • States are the intermediate datasets produced by each node.
  • The compiler can then optimize, reorder, and validate these transformations.

Environment Considerations

  • Linux (Rscript + PSPP easily installed)
  • Windows: R via VS Code, PSPP absent -> configurable commands or skip

Usage

python src/compiler.py --manifest demo/input/logic.sps \
  --pspp-cmd "echo PSPP skipped" \
  --rscript-cmd Rscript
